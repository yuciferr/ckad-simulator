## Bu Oturumda Tamamlananlar — kubectl Simulation

### 1. Standardize Success/Fail Outputs

| Komut | Çıktı formatı |
|-------|---------------|
| `create` | `deployment.apps/name created`, `service/name created` |
| `delete` | `"name" deleted` — kaynak yoksa error |
| `apply` | `deployment.apps/name created` |
| `scale` | `deployment.apps/name scaled` |
| `label` / `annotate` | `resource/name labeled/annotated` |
| `rollout undo` | `deployment.apps/name rolled back` |
| `rollout status` | `deployment "name" successfully rolled out` |

### 2. Validation Layer

- Missing name: `error: missing required argument 'name'`
- Resource not found: `error: resource "deployment" "name" not found`
- Invalid replicas: `error: --replicas accepts int, received 'xyz'`
- Protected namespace: `error: Forbidden: namespace "kube-system" is protected`

### 3. Rollout Commands

- `rollout status` — deployment existence check
- `rollout undo` — confirmation mesajı
- `rollout history` — revision listesi
- `rollout restart` — restart trigger
- `RESOURCE/NAME` format desteği (`deployment/name`)
