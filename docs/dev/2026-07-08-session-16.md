# Session 16 — Mock Exam 2 + practice module expansion

## Context
User asked for a new CKAD mock exam aligned to the 2026 curriculum and
Kubernetes v1.35, plus expansion of any thin/underdeveloped practice modules.

## What was built

### `exams/mock/2/` — new full mock exam (registered in `exams/manifest.json`)
- 20 questions, 120 min, weights sum to 100, spanning all five CKAD domains
  including topics not covered by mock/1: native sidecars (`initContainer`
  `restartPolicy: Always`), DaemonSet, blue/green switch, Kustomize overlay,
  Helm install/upgrade, full probe triad, API-deprecation rewrite
  (`networking.k8s.io/v1beta1` → `v1`), custom resource from a pre-installed
  CRD, and HorizontalPodAutoscaler (`autoscaling/v2`).
- Per-question `scenarios/qN/setup.yaml` (namespace + seeded/broken fixtures,
  e.g. q8's Deployment ships with a broken command to reproduce
  CrashLoopBackOff, q16's Service ships with wrong selector/targetPort).
- `course/` seeds: Kustomize base (p5), a working local Helm chart (p6/webchart),
  a deprecated-API Ingress to rewrite in place (p9), plus README placeholders.
- `answer.json` checks use the shared `resource`/`path`/`equals`/`contains`
  grading engine; DaemonSet/HPA/custom-resource checks fall back to
  `command` assertions since those kinds aren't in `CLUSTER_RESOURCES`
  (`src/sandbox/evidence.ts`).

### Practice module expansion
Thinnest modules grown (question count doubled+, weights renormalized):
- `multi_container_pods`: 2 → 8 (ordered init containers, native sidecar,
  ambassador, adapter, in-memory `emptyDir`, shared process namespace)
- `crd`: 4 → 8 (describe CRD, inspect CR as YAML, cluster-scoped CRD, delete CR)
- `state`: 6 → 12 (ConfigMap/Secret volumes, `emptyDir.sizeLimit`, hostPath,
  read-only PVC mount, downwardAPI volume)

Ran `npm run assign:practice-namespaces` after editing — new questions
correctly inherited their module's existing group namespace segment.

### Supporting fix
`scripts/validate-scenarios.js` hardcoded `validateMockExam('1')`, so it
never checked mock/2's scenarios. Changed it to iterate `manifest.mock`
(falling back to `['1']` if `manifest.json` is missing).
