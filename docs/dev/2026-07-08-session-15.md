# Session 15 — CK-X competitive analysis + one-shot installer

## Context
The user found CK-X (github.com/sailor-sh/CK-X), a similar Kubernetes cert
simulator, and asked for (1) a competitive analysis + roadmap to make our CKAD
simulator "complete and unrivaled" (CKAD focus only), and (2) a single install
`.sh` that preflights prerequisites and brings the stack up in Docker.

Full plan: `~/.claude/plans/groovy-strolling-kite.md`. Decisions with the user:
terminal-first (no VNC desktop), keep client-side grading, prioritize an
analytics/weak-area report, and **build only the install script this pass**.

## Analysis summary (CK-X vs. us)
- CK-X is ahead on: full noVNC desktop + SSH-to-node jumphost + multi-node
  (too heavy for us — skipped); per-question difficulty + `concepts[]` domain
  tags (→ adopt for analytics); warm-up timer; wake lock; rank-badge results;
  one-liner installer.
- We're ahead on: per-question instant "Check" (they grade only at exam end),
  declarative checks engine, practice mode + resume + hints, 167 vs 41
  questions, kind vs k3d, 2 vs 8 services.
- License: CK-X is BSL 1.1 — ideas only, our own code.

## What was built
- `install.sh` (repo root, executable): idempotent one-shot installer.
  - Preflight: repo-root assertion, Docker installed + running, Compose v2,
    curl/wget, arch→TARGETARCH, port free (with `--port`/`PORT` override, honored
    by docker-compose `${PORT:-3000}:3000`), non-fatal RAM warning.
  - Idempotency: if the port is held by our own stack (detected via our
    `/health` payload containing `"mode"`), it's treated as a re-run, not a
    conflict.
  - Bring-up: `PORT=… TARGETARCH=… docker compose up --build -d`.
  - Readiness: polls `/health` until HTTP 200 + `.cluster.ready==true` (jq or
    grep fallback), spinner, ~7 min timeout → points at `docker compose logs`.
  - Finish: prints URL, opens browser (`--no-browser` to skip), lists commands.
  - Flags/env: `--port`, `--no-browser`, `--help`, `PORT`.
- `Makefile`: added `install` target → `./install.sh`.
- `README.md`: Quick Start rewritten around `./install.sh`.

## Verification
- `bash -n` clean; `--help` and invalid-`--port` rejection work.
- Ran `./install.sh` end-to-end against the live stack: preflight passed,
  idempotent re-run correctly detected (port 3000 = our app), compose build
  reconciled from cache, blocked until `/health` ready, printed URL + commands.
- Docker-down and real-port-conflict messages are wired but not force-triggered
  (avoided disrupting the running stack).
