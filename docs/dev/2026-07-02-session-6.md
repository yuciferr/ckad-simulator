## Kritik Bug Fix — Terminal "Cannot read properties of undefined (reading 'spawn')"

**Kök neden:** `src/ws/terminal.ts` içinde `import pty from 'node-pty'` → derlenmiş kod `node_pty_1.default.spawn(...)` çağırıyordu. `node-pty` CommonJS modülünde `.default` yok; `pty` undefined oluyordu.

**Düzeltme:**
```typescript
import * as pty from 'node-pty';
// dist/ws/terminal.js → pty.spawn(...) ✓
```

**Doğrulama:**
- WebSocket smoke test: `created` + shell output ✓
- Playwright: sınav açılınca terminal hatası yok ✓
- Refresh sonrası terminal hatası yok ✓

> **Not:** Fix'in aktif olması için sunucunun yeniden başlatılması gerekir (`npm run dev` veya `node server.js`).
